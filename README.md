## Projetos em destaque

### [Agentic RAG com Google Cloud](https://github.com/PedrovSilva/agentic-rag-gcp)
Projeto de estudo e desenvolvimento de uma aplicação de **Retrieval-Augmented Generation (RAG)** com arquitetura orientada a agentes, backend em Python/FastAPI e foco em integração com serviços de IA e Google Cloud.

**Tecnologias:** Python, FastAPI, React, PostgreSQL/pgvector, Vertex AI, Docker.

### [TaskAPI — Go](https://github.com/PedrovSilva/taskapi-goland-studies)
API REST para gerenciamento de tarefas, desenvolvida para praticar organização de backend e boas práticas em Go.

**Destaques:** separação Handler/Service/Repository, PostgreSQL, validação, propagação de context, encerramento gracioso, endpoints de health/readiness e testes automatizados.

### [Classifieds Application](https://github.com/PedrovSilva/Classifieds-Application)
Aplicação full stack de classificados, com interface em React e API em .NET, voltada à implementação de operações CRUD e integração entre frontend e backend.

**Foco técnico:** ASP.NET Core, Entity Framework Core, SQL Server, validação, paginação, documentação de API e conteinerização.

### [Genetic Syndrome Classification Pipeline](https://github.com/PedrovSilva/Genetic-Syndrome-Classification-Pipeline)
Pipeline de Machine Learning para classificação de síndromes genéticas a partir de image embeddings, com experimentos usando KNN e comparação de métricas e configurações.

**Resultados de referência:** avaliação por indivíduo com 1.116 imagens, 941 indivíduos e 10 classes; configuração com similaridade cosseno alcançou 74,66% de Top-1 e 89,84% de Top-3 no benchmark documentado.
